Ba bước, vài phút cho mỗi kỳ khuyến mãi

Không còn dò từng dòng trong Excel. Tool ghép, đối chiếu và tô màu thay bạn.

1

Tải file

Kéo thả file formula (giá hiện tại, có thể là file trắng) và file template (giá mới). Tool tự nhận ra file nào là file nào.

2

Kiểm tra

Xem mã đổi giá, mã thêm mới và những dòng cần xem lại: cùng kỳ mà khác giá, hoặc ngày kết thúc trước ngày bắt đầu.

3

Xuất file

Tải về Directo_Upload.xlsx kèm sheet Report. Dòng đổi giá tô xanh lá, dòng mới tô xanh dương, mã lặp tô vàng.

Thấy hết mọi thay đổi trước khi upload

Một màn hình cho biết bao nhiêu dòng sẽ lên Directo, dòng nào đổi giá bao nhiêu, và dòng nào cần liên hệ PIC.

  • Cảnh báo ngay: mã có nhiều giá trong cùng kỳ, ngày kết thúc trước ngày bắt đầu.
  • Biểu đồ mức đổi giá: dòng nào tăng hay giảm bất thường thì nhìn là thấy.
  • Đánh dấu đã xem: đi lần lượt từng dòng cần xem, không bỏ sót.

Hỏi đáp

File formula đang trắng thì có dùng được không?

Được. Khi file formula chỉ có dòng tiêu đề, toàn bộ dòng trong template sẽ được điền vào như dòng mới, cột E là Static và cột F là 2.

File của tôi có bị gửi lên mạng không?

Không. Trang chỉ đọc file ngay trong trình duyệt của bạn để tạo file upload, file gốc cũng không bị sửa.

Tool đọc file template ở đâu?

Sheet đang mở khi lưu file, cột B đến E từ dòng 26: mã, giá mới, ngày bắt đầu, ngày kết thúc. File formula đọc sheet đầu tiên, cột B đến I từ dòng 2.

Dòng "cần xem lại" là gì?

Là mã có nhiều giá trong cùng một kỳ khuyến mãi (cần liên hệ PIC để chốt) và dòng có ngày kết thúc trước ngày bắt đầu. Các dòng này vẫn nằm trong file và được ghi lại ở sheet Report.

File tải về gồm những gì?

Sheet Directo_Upload để import vào Directo, và sheet Report tổng hợp số dòng, mã mới, mã cập nhật cùng danh sách mã lặp lại.
